# Security Policy

Do not include credentials, private keys, internal source, device logs, or
sensitive infrastructure details in an issue or pull request.

Report suspected vulnerabilities through the repository's GitHub Security
Advisory **Report a vulnerability** action. If private reporting is unavailable,
contact the maintainers through an approved private channel before disclosing
technical details publicly.

Include the affected version, impact, minimal reproduction, and any suggested
mitigation. Do not test against systems, CI services, or devices you are not
authorized to operate.
