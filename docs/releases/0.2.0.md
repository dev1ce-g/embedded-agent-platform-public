# 0.2.0 Release Candidate Acceptance

Status: **release candidate merged into `main`; software CI passed on the
release branch; not tagged or published as a GitHub Release**.

This record freezes the `0.2.0` delivery boundary. It is an acceptance record,
not a claim that hardware or external services were exercised.

## Included

- Trellis-free project projection, Rule Pack, Discovery, migration, and doctor.
- Model-independent Mac, WSL, and Windows command boundaries.
- Capability Contract v1 result/request schemas and typed persistent Job v2.
- Runtime path, identity, connection, reset, and container hardening already
  covered by software tests.
- Public documentation and `0.1` to `0.2` upgrade guidance.

## Explicitly Deferred

- Stateful Catalog, Preflight/input binding, Approval, and Receipt handlers.
- A published SDK Manager and adapter conformance kit.
- An open simulator or board execution Golden Path.
- Real toolchain, Docker build, Jenkins service, signing, flashing, CAN, RTT,
  and target-hardware validation.

These items are roadmap work. They do not reopen the `0.2.0` architecture.

## Architecture Invariants

1. The model owns reasoning and orchestration.
2. The platform owns context, rules, fixed capabilities, gates, durable state,
   and evidence.
3. No default path requires Trellis, a workflow/task store, or a model-specific
   launcher.
4. Legacy state is read only by explicit, non-destructive migration.
5. External side effects remain behind fixed commands and confirmation gates.

## Software Acceptance

Run from the repository root:

```bash
PYTHONPYCACHEPREFIX=/tmp/embedded-agent-platform-pycache \
  python3 -m unittest discover -s bootstrap/tests -v

(
  cd runtime/windows/embedded-agent
  PYTHONPYCACHEPREFIX=/tmp/embedded-agent-platform-pycache \
    python3 -m unittest discover -s tests -v
)

bash -n install.sh runtime/mac/bin/embedded-agent runtime/wsl/bin/embedded-agent
git diff HEAD --check
```

integrity checks. GitHub Actions repeats the software suites on its supported
